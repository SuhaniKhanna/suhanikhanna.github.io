🌐 **Live at:** [suhanikhanna.github.io](https://suhanikhanna.github.io)

A personal portfolio website built from scratch to showcase my journey as an aspiring Data Scientist.

## Sections

- **Hero** — Introduction with animated role titles and key stats
- **About** — My background, education timeline, and interests
- **Skills** — Technical and soft skills
- **Projects** — Featured data science and development projects
- **Testimonials** — Feedback from teammates and mentors
- **Contact** — Links and ways to reach me

## Built With

- HTML5 & CSS3
- Vanilla JavaScript
- Fonts: Syne + DM Sans (Google Fonts)
- Deployed via GitHub Pages
